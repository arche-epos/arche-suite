# Grounding data for Pilgrim Private AI Study Tools

Generated by a one-time transform (not tracked in git as a build step — re-run manually if upstream
data updates). See `spec-ai-tools-grounding-v1.md` for the tools that consume this data and why.

## Contents

- `macula/<NN>.json` — per Bible book (01=Genesis…66=Revelation), per-verse ("chap:verse" key) ordered
  list of original-language words: `{word, lemma, strongs, morph, gloss}`.
  - NT (40-66): Greek text, Strong's numbers, morphology, and English gloss from **MACULA Greek**
    (Clear-Bible/Biblica), CC BY 4.0. Source: SBLGNT tsv.
  - OT (01-39): Hebrew text, lemma/Strong's numbers, and morphology from the **Open Scriptures
    Hebrew Bible** (openscriptures/morphhb) — the same underlying source MACULA Hebrew is itself
    built from. Substituted for MACULA Hebrew directly because that repo's TSV export is
    Git-LFS-hosted and wasn't reachable from the build environment; the lexical/morphological
    content is the same. `gloss` is empty for OT entries (OSHB does not include English glosses).
- `crossrefs/<NN>.json` — per verse, top-8 cross-references by community vote weight:
  `[[ "Book Chap:Verse", votes ], ...]`. Source: **OpenBible.info Cross-References** (Treasury of
  Scripture Knowledge, vote-weighted), CC BY.
- `strongs/greek.json`, `strongs/hebrew.json` — full Strong's Hebrew & Greek Dictionaries (lemma,
  transliteration, pronunciation, derivation, definition, KJV renderings), keyed by Strong's
  number. Source: **Open Scriptures** (openscriptures/strongs). CC BY-SA (tagging) / Public Domain
  (underlying Strong's text).
- `strongs/gloss-index.json` — English word → candidate Strong's numbers, built solely from each
  entry's own KJV-rendering list in the Strong's dictionaries above. Used to constrain the Word
  Study lexicon lookup's ambiguous-word candidate list to real Strong's numbers instead of
  model-invented ones.
- `strongs/occurrences.json` — Strong's number → up to 30 real verse references where it occurs
  (derived from `macula/`, one entry per verse, canonical book order). Used to ground the Word
  Study lexicon lookup's "occurrences" list — the app fetches the actual verse text for these refs
  via its existing translation API rather than having the model generate it.
